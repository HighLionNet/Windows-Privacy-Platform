# History — Version 1.1

**Milestone date:** 2026-07-25  
**Document role:** Historical record of the management-console presentation hardening pass.

---

## Context

v1.0 shipped a functional WPF host, but presentation still showed residual card stacking: every subsection lived in its own bordered `PropertyGroup`/`Card`, domain pages felt fragmented, and setting detail pages read like stacked blog blocks rather than Windows property sheets.

Backend remained frozen. This release is presentation-only.

---

## Goals

1. Kill AI-slop / stacked-card aesthetics  
2. Make the UI feel like Event Viewer / Services / MMC / gpedit  
3. Stronger hierarchy and denser, scannable pages  
4. Unambiguous current / effective / source / confidence / reason  
5. Stronger left navigation with domain group color identity  
6. No backend, no scores, no writes  

---

## What changed

### Styles (`AppStyles.xaml`)

- Introduced `PropertySheet` + `PropertySheetHeader` + `SheetLabel` / `SheetValue` for MMC-style tables  
- `PropertyGroup` reduced to transparent layout helper (no more nested boxes by default)  
- `DomainTile` style: flat buttons with left accent bar  
- Domain group color brushes (Privacy / Security / Windows / Apps / Knowledge)  
- Slightly stronger sidebar selected/hover surfaces  

### Home / Machine Overview

- Replaced 3-column nested PropertyGroup boxes with **two single property sheets** (Identity, Security posture) + one Scan sheet  
- Attention banner only when conflicts exist  
- Domain entry points use `DomainTile` (left accent, no nested chrome)  
- Secondary evidence behind expanders without inner cards  

### Setting detail

- Single primary **Configuration state** property sheet: Observed · Effective · Source · Confidence · Reason  
- What / Why / Impact are plain text under section headers — **no boxes around paragraphs**  
- Long guidance and evidence behind expanders  
- Related settings remain dense list rows  

### Domain / Conflicts / Knowledge / Search

- Domain list: denser rows, uppercase subcategory headers, clearer status column  
- Conflicts: single-column readable rows; Effective + source on one line; reason below  

### Shell

- Sidebar width 240px  
- Group labels tinted with domain identity colors  
- Version string **v1.1**  

### About

- Property-sheet layout matching the rest of the app  

---

## Unchanged

- Collectors, binders, PolicyPrecedenceResolver, ValueSemantics, catalog  
- ScanService pipeline  
- CLI / TUI  
- Safety model  

---

## How to verify

```powershell
cd Source
dotnet build -c Release
cd WindowsPrivacyPlatform.App
dotnet run -c Release
```

Check: Home is two sheets not six boxes; setting detail is one primary grid; nav group labels are colored; domain tiles on Home are flat with left accent.
