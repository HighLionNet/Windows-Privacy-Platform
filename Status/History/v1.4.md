# History — Version 1.4

**Milestone date:** 2026-07-29  
**Document role:** Historical record of the GUI information-architecture correction (presentation only).

---

## Context

v1.3 improved colors, typography, and some navigation, but domain pages remained **stacked setting cards** (current, effective, options table, left accent on every row). That design overloaded index pages with detail that belongs deeper in the hierarchy and did not scale toward larger catalogs.

Backend remained frozen. This release is presentation-only.

---

## Goals

1. Page-oriented hierarchy: Home → Domain → Category → Setting detail  
2. Domain pages = category indexes (not setting cards)  
3. Category pages = scannable setting lists with column headers  
4. Setting detail = only place for options, provenance, educational expanders  
5. Remove repeated labels, nested cards, and options from index pages  
6. Preserve mid-cyber restrained palette and existing shell  
7. No backend, no scores, no writes  

---

## What changed

### DomainView

- Replaced `BuildSettingCard` stack with category index list  
- Columns: Category / Settings / Attention  
- Conflict counts surface without opening every setting  
- Click opens CategoryView  

### CategoryView (new)

- Setting index list with columns: Setting / Current / Effective / Status  
- Alternating row background; conflict left-accent via ListRowConflict  
- No options table, no per-row "Current setting:" labels  
- Click opens SettingDetailPage  

### SettingDetailPage

- Single State property sheet (Current, Effective, Source, Confidence, Reason)  
- Available values as compact table when ValueSemantics exist (hidden otherwise)  
- Summary always visible; secondary knowledge remains in expanders  

### MainWindow

- Navigation tags: `category:{ProductDomain}:{SubCategory}`  
- Breadcrumbs include Category segment  
- Version string v1.4  

### Unchanged

- Collectors, binders, PolicyPrecedenceResolver, ValueSemantics, catalog  
- ScanService pipeline  
- CLI / TUI  
- Safety model  
- Sidebar domain list and Home property sheets
